# Ayush Sagar — Portfolio

A responsive dark-first developer portfolio built with vanilla HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Customize
- Replace the initials avatar with a real profile photo when ready.
- Add projects in the Projects section.
- Add your PDF resume and change the Resume button to a direct file link.
- Update social/profile URLs if needed.

## Deploy
Works as a static site on GitHub Pages, Netlify, or Vercel.
